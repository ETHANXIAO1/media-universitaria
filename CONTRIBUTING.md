# Contributing

Thanks for your interest in improving **Media Universitaria**! 🎉

This project is intentionally small and beginner-friendly. You don't need any
build tools — just a browser and, for the tests, Node.js.

## Getting started

1. Fork and clone the repository.
2. Open `index.html` in your browser (or use VS Code's *Live Server*).
3. Run the tests with `npm test` (or `node --test`).

## How to contribute

1. Create a branch: `git checkout -b my-change`
2. Make your change and, if you touched `src/calc.js`, add or update a test.
3. Make sure the tests pass: `npm test`
4. Open a pull request describing what you changed and why.

## 💡 Good first issues

Some ideas to get started, roughly from easiest to hardest:

- [ ] Show a friendly message when there are no exams yet.
- [ ] Add an English / Italian language switch.
- [ ] Let users reorder exams (move up / down).
- [ ] Add a "30 e lode counts as 31" option for the projection (some universities use this).
- [ ] Export the exam list to a CSV file.
- [ ] Add a progress bar toward a target graduation mark.
- [ ] Improve accessibility (labels, keyboard navigation).

Found a bug or have an idea not listed here? Please open an issue!
